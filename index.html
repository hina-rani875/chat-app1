Kyun Gupshup?

⚡

Instant messages

Firebase Firestore se messages dono taraf live sync hote hain.

🔐

Secure auth

Email + password se sign up aur login, Firebase Authentication ke saath.

🖼️

Photo sharing

Cloudinary se profile photo aur chat images tezi se upload hoti hain.

🟢

Online status

Dekho kaun online hai aur last seen kab tha.

Typing indicator

Mobile friendly
